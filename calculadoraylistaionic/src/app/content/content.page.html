ion-content

El componente de contenido proporciona un área de contenido fácil de usar con algunos métodos útiles para controlar el área desplazable. Solo debe haber un elemento de contenido por vista. El contenido, junto con muchos otros componentes de Ionic, se puede personalizar para modificar su relleno, margen y más utilizando los estilos globales proporcionados en las utilidades CSS o aplicándole estilos individualmente utilizando CSS y las propiedades personalizadas CSS disponibles .
