Accordion

ion-accordion

Un acordeón agrupa secciones de contenido que se pueden expandir o colapsar. Ejemplo con tres secciones:

¿Qué es Ionic?
Ionic es un framework para crear aplicaciones móviles con HTML, CSS y JavaScript/TypeScript.
¿Qué es Angular?
Angular es un framework de desarrollo web mantenido por Google, usado como base de este proyecto.
¿Para qué sirve este ejemplo?
Para mostrar cómo se usa el componente ion-accordion en una app real.
